# Modelagem_de_Banco_de_Dados_SGBD

# 🗄️ Modelagem de Banco de Dados e SGBD

Este repositório reúne estudos, projetos, exercícios e implementações práticas focados em **Modelagem de Banco de Dados** e no uso de **Sistemas Gerenciadores de Banco de Dados (SGBD)**.

O objetivo principal é documentar a evolução no aprendizado sobre estruturas de dados relacionais (e não-relacionais), desde o design conceitual até a implementação de consultas otimizadas.

---

## 📌 Conteúdo do Repositório

- **Modelagem Conceitual:** Diagramas Entidade-Relacionamento (DER).
- **Modelagem Lógica:** Mapeamento do modelo conceitual para o modelo relacional (Tabelas, Chaves Primárias, Chaves Estrangeiras e Normalização).
- **Modelagem Física:** Scripts SQL para criação de bancos de dados (`CREATE DATABASE`, `CREATE TABLE`).
- **Manipulação e Consultas (DML/DQL):** Scripts de povoamento e consultas com `SELECT`, `JOIN`, `GROUP BY`, views e procedimentos.
- **Práticas em SGBDs:** Projetos aplicados em SGBDs como PostgreSQL, MySQL, SQL Server ou SQLite.

---

## 🛠️ Tecnologias e Ferramentas

- **Linguagens:** SQL
- **Ferramentas de Modelagem:** One Compiler, brModelo, MySQL Workbench, Draw.io
- **SGBDs Utilizados:** PostgreSQL / MySQL / SQLite / OneCompiler
